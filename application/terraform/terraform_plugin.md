## Terraform Plugn



## Attributes

- 1. Required only - the user must provide a value
- 2. Optional only - the user can configure or omit a value; do not use Default or DefaultFunc
- 3. Computed only - the provider can provide a value but the user cannot, i.e., read-only
- 4. Optional AND Computed - the provider or user can provide a value; use this combination if you are using Default
