## statistics

## Company

Comapny name

- allowed characters
    - https://www.moj.go.jp/MINJI/minji44.html
    - kanji
    - kana
    - alphabet
    - number
    - special characters:
    　　- `＆`
        - `’`
        - `，`
        - `‐`
        - `．`
        - `・`
    - half width is not allowed. All must be full width.
- no limitation for company name length
    - however, systems to register the company name may have limitation so that practically the name is not too long.
